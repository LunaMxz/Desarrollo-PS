# Sistema de Gestion de Condominios

Proyecto de la materia Desarrollo de Proyectos de Software (agosto-diciembre 2026).

## Estructura del repositorio

```
/backend   -> API REST (Node.js + Express + PostgreSQL)
/frontend  -> Cliente web (React + Vite)
/docs      -> Contexto del proyecto y casos de uso
```

## Como levantar el proyecto

1. Backend: ver `backend/README.md`
2. Frontend: ver `frontend/README.md`

## Convenciones de ramas

- `main`: codigo estable, solo se llega via Pull Request.
- `develop`: rama de integracion del sprint actual.
- `feature/<nombre-tarjeta>`: una rama por tarjeta de Planner (ej. `feature/cu01-login-backend`).
